# Plan grill loop

The plan grill loop chains three of Matt Pocock's skills into one habit: grill me, to spec and to tickets.
When an issue gets the label idea, your agent grills you about it with grill me, writes the spec with
to spec and splits it into tickets with to tickets. A hard check makes sure the spec has acceptance
criteria and every ticket links it.

- Trigger: issue labelled idea (GitHub Actions or Claude Code routine)
- Verification: you answer, plus a spec check (acceptance criteria, every ticket links the spec, no open questions)
- Memory: `workflows/NOTES.md`
- Built from: `mattpocock/grill-me`, `mattpocock/to-spec`, `mattpocock/to-tickets` (MIT)
